# Token之庭

**把大模型的底层原理，拆成能上手玩的东西。**

一个纯前端的交互式实验室。三个实验，每个回答一个具体的困惑 —— 不是教程，是能自己动手拨动参数、立刻看到结果的地方。

在线地址：https://token-garden.app.workbuddy.host/

## 三个实验

### 01 · BPE 分词实验室

**回答：模型看到的不是字，是 token —— 以及为什么中文比英文贵那么多。**

- 粘贴任意文本，看它被切成什么样子；空格、换行、制表符都会被显式画出来（`·` `↵` `⇥`），所以你能肉眼校验「所有块拼回去 = 原文」
- 鼠标悬停任意一块，显示它的 token id 和字符数
- **中英对比**：三组同语义的句子并列，直接看出差距

**这组数字是整站最值得记住的**：

| | 中文 | 英文 |
|---|---|---|
| 「人工智能正在改变我们编写软件的方式。」 | 18 字 → 11 token（压缩比 **1.64**） | 62 字 → 10 token（**6.20**） |

同一句话的意思，token 数几乎一样，但**中文花的钱是英文的 3.8 倍**。

还有个反直觉的发现：「月光洒在寂静的湖面上，微风拂过，泛起层层涟漪。」——
23 个字切出了 **28 个 token**，压缩比跌到 **0.82**。
说明中文贵多少跟你的**用词常不常见**直接相关，不只是语言特性。

### 02 · 上下文与 KV Cache

**回答：聊天记录越长，为什么越慢、越贵、越容易崩。**

拖动对话轮数和每轮长度，看三条曲线怎么分道扬镳：

- **上下文长度** —— 线性涨
- **KV cache 显存** —— 线性涨
- **Attention 计算量** —— 按**平方**涨

实测数据（LLaMA-3 8B，每轮 512 token）：从第 1 轮到第 16 轮，显存涨 16 倍，
**计算量涨 251 倍**。

页面上的公式和模型参数都是可核对的（满窗 8K / fp16 时 KV cache 正好 1.00 GB，
与业界公开数据一致）。

### 03 · BPE 词表是怎么长出来的

**回答：那些 token 到底从哪来的。**

从字符开始，一步步播放合并过程：每步合并了哪两个符号、这对在语料里出现多少次、
词表怎么从 8 个长到 18 个。算法自己实现，没用任何库。

经典案例：`hug hug hug pug pug pun pun pun bun bun hugging` 训练十步后，
`hug` / `pun` / `pug` / `bun` 各自收敛成单独一个 token。

### 04 · 上下文预算与成本

**回答：一次对话到底花多少钱，钱花在哪。**

输入你的用量（system prompt 长度、轮数、每次输入输出、日均会话数），算出单次 / 日 / 月成本，
并把成本拆成四项：**重复发送的历史 / system 重发 / 本轮新输入 / 模型输出**。

结论通常不太好受：**大部分钱花在反复重发旧内容上**，只有小部分在「新说的话」上。

页面上还有 prompt 缓存的开关 —— **缓存价普遍是输入价的 1/10**，
打开就能看到月成本直接掉一个量级。

## 价格数据怎么更新

成本实验依赖静态价格表 `src/labs/cost/pricing.ts`。数据会过期，页面会在超过 60 天后弹提示。

更新步骤（也写在那个文件的顶部注释里）：

1. 拉 OpenRouter 的公开接口（无需鉴权）：`https://openrouter.ai/api/v1/models`
2. 它返回的是「每 1 个 token」的美元价，本表存的是「每 100 万 token」，记得 **× 1e6**
3. 改 `PRICES` 里的数字，并把 `FETCHED_AT` 改成当天日期
4. `npm run build` 确认没报错

> 注：价格来自 OpenRouter 的公开报价，与厂商直连价可能有出入
> （例如 GPT-5.6 Sol 官方 $4/1M，OpenRouter $2）。页面底部有明确标注。

## 一些设计上的取舍

**不接任何 LLM API，不做后端，不做数据库，全静态。**
所有计算都在你的浏览器里跑，不发一个请求，不上传任何数据。

**唯一克制的依赖。** 运行时只引入了 `gpt-tokenizer`（真实词表）。
BPE 训练过程、KV cache 计算、成本模型全部自己实现 —— 代码量比引库还小，而且能读懂。

**词表 1MB，但不进主包。** 用 `import()` 动态加载，进首页时只下 99 kB；
鼠标划过首页卡片时就开始后台预热，点进去基本不用等。

**视觉是爱莉希雅（《崩坏3》）的粉白调性，但不使用任何角色素材。**
氛围用几何图形和配色营造 —— 版权干净，也不抢数据的注意力。
